1.	Изначально капуста, волк, фермер и коза на одном и том же берегу (S26);  
шаги 2-4 помещены в блок do … od;  
2.	Выходим из цикла do по условию (f==1) && (f == w) && (f == g) && (f==c) -> all_right_side = true;  
3.	Иначе: если несколько из условий (f==w); (f==g); или (f==c) выполнимы, то недетерминированно выполняется одна из последовательностей действий, соответствующая выполненному условию:  
a.	f = (1-f); w = (1-w); // Фермер забирает волка на другой берег  
b.	f = (1-f); g = (1-g); // Фермер забирает козу на другой берег  
c.	f = (1-f); c = (1-c); // Фермер забирает капусту на другой берег  
d.	f = (1-f); // Фермер просто уплывает на другой берег  
4.	Аналогично шагу 3, по условиям (f!=g && g==c); или (f!=w && w==g) выполняется  
a.	g_and_c = true; // Коза и капуста остались на одном берегу  
b.	w_and_g = true; // Волк и коза остались на одному берегу  
c.	else skip; // иначе ничего не делаем
